### String

- new 대신 “홍길동” 과 같;은 문자열로 인스턴스 생성

```java
String name = "홍길동"
String test = "홍길동";
String obj = new String("홍길동"); // Heap

System.out.println(name == test); // true
System.out.println(obj == test); // false

System.out.println(test.equals(obj)); // true
```

- String Pool
    - 큰따옴표를 활용해서 문자열 객체를 생성하면 String Pool에 들어감
    - new keyword, 생성자를 이용해서 문자열 객체를 생성하면 일반적인 Heap 영역에 들어감
    - String Pool에 들어가면 immutable한 특성을 가짐
- 비교를 할 때 같은 주소냐를 보지 않고 같은 내용이냐를 봄
    - 그러면 `==`를 사용하는 것 말고 `equals()`를 사용해야 함

### Array

- 배열과 같은 type의 데이터를 여러 개 저장할 수 있는 자료구조
- 배열은 객체임
- 배열을 만들기 위해 new 키워드를 사용함
- 제네릭으로 타입 명시
- List
    - List와 같은 인터페이스를 상위 타입으로 해서 선언하면 프로그램의 유연성이 높아짐
    - ArrayList
        
        ```java
        ArrayList list = new ArrayList();
        
        //list 계열을 사용할 때에는 Generic이 기본임
        ```
        
        - 배열과 유사함
        - 크기가 유동적임
        - 서로 다른 데이터 타입 저장 가능
        - primitive 타입을 저장할  수 없음
            - 원래 wrapper class로 감싸서 해결해야 하는데 `autoboxing`이 일어나서 wrapper클래스 로 저장됨
            - 오토박싱은 primitive data가 wrapper class를 받는 곳을 통과할 때 적용됨
- Map
    - HashMap
        - 키와 밸류의 쌍으로 이루어짐
        - 집합형 자료구조
        - 순서 개념이 없음
        - 둘 다 객체만 사용함
    
    ```java
    //위와 같은 이유로 상위 타입으로 선언하는 것이 일반적
    Map map = new HashMap();
    ```
    
    - put()

    - add()

package javaexam2;

import java.util.StringTokenizer;

public class Test03 {
    public static void main(String[] args) {
        String str = "1.22,4.12,5.93,8.71,9.34";
        double[] data = new double[5];
        double sum = 0;

        StringTokenizer st = new StringTokenizer(str, ",");
        for(int i = 0; st.hasMoreElements(); i++) {
        data[i] = Double.parseDouble(st.nextElement().toString());
        sum += data[i];
        }

        System.out.printf("합계: %.3f\n",sum);
        System.out.printf("평균: %.3f\n", sum/data.length);
    }
}

package javaexam2.plane;

public abstract class Plane {

    private int fuelSize;

    public Plane() {}
    public Plane(String planeName, int fuelSize) {
        this.planeName = planeName;
        this.fuelSize = fuelSize;
    }

    public String getPlaneName() {
        return planeName;
    }
    public int getFuelSize() {
        return fuelSize;
    }
    public void setPlaneName(String planeName) {
        this.planeName = planeName;
    }
    public void setFuelSize(int fuelSize) {
        this.fuelSize = fuelSize;
    }

    public void refuel(int fuel) {
        this.fuelSize += fuel;
    }
    public abstract void flight(int distance);
}

public abstract class Employee {
    private String name;
    private int number;
    private String department;
    private int salary;

    public Employee() {}
    public Employee(String name, int number, String department, int salary) {
        this.name = name;
        this.number = number;

        this.salary = salary;

    public abstract double tax();

    public String getDepartment() {
        return department;
    }

    public void setDepartment(String department) {
        this.department = department;
    }

    public int getSalary() {
        return salary;

    public void setSalary(int salary) {
        this.salary = salary;
    }

    public int getNumber() {
        return number;
    }

    public void setNumber(int number) {
        this.number = number;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}

package javaexam2.company;

import java.util.HashMap;
import java.util.Map;

public class Company {
    public static void main(String[] args) {
        Map<Integer, Employee> map = new HashMap<Integer, Employee>();
        // 1번의 데이터를 기반으로 객체를 생성 하여 HashMap에 넣는다.
        // HashMap에 넣을 때 키 값은 각 객체의 Number로 한다.

        Secretary e1 = new Secretary("Hilery", 1, "secretary", 800);
        Sales e2 = new Sales("Clinten", 2, "sales", 1200);

        map.put(e1.getNumber(), e1);
        map.put(e2.getNumber(), e2);

        // 모든 객체의 기본 정보를 출력 한다(for문을 이용하여 출력 한다.)
        System.out.printf("%-15s%-20s%-9s\n", "name", "department", "salary");
        System.out.println("-------------------------------------------");
        for (Integer key : map.keySet()) {
            Employee emp = map.get(key);
            System.out.printf("%-15s%-20s%-9s\n", emp.getName(), emp.getDepartment(), emp.getSalary());
        }
        System.out.println();
        // 모든 객체에 인센티브 100씩 지급하고 다시 HashMap에 넣는다.
        e1.incentive(100);
        e2.incentive(100);
        System.out.println("인센티브 100 지급");
        // 모든 객체의 정보와 세금을 출력 한다 (for문을 이용하여 출력 한다.)
        System.out.printf("%-15s%-20s%-9s%-9s\n", "name", "department", "salary", "tax");
        System.out.println("---------------------------------------------------");
        for (Integer key : map.keySet()) {
            Employee emp = map.get(key);
            System.out.printf("%-15s%-20s%-9s%-9s\n", emp.getName(), emp.getDepartment(), emp.getSalary(), emp.tax());
        }
        System.out.println(); 
    }
}
