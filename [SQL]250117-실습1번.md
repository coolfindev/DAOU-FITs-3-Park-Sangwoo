### 문제

- 직원의 직무 변경 기록과 상태
    
    ```sql
        SELECT E.NAME, 
        CASE 
            WHEN COUNT(*) >= 2 THEN J.JOB_ID
            ELSE 'NO Change'
        END
        FROM EMPLOYEES E
        LEFT JOIN JOB_HISTORY J
        ON J.EMPLOYEE_ID = E.EMPLOYEE_ID
        GROUP BY E.NAME, J.JOB_ID;
    ```
    
- 특정 패턴의 직원과 부서 정보 조회
    
    ```sql
        SELECT NAME, 
        CASE 
            WHEN SALARY IS NULL THEN 0
            ELSE SALARY
        END 급여,
        D.DEPARTMENT_NAME 소속부서
        FROM EMPLOYEES E
        LEFT JOIN DEPARTMENTS D
        ON E.DEPARTMENT_ID = D.DEPARTMENT_ID
        WHERE NAME LIKE '%Employee 1%'
        ORDER BY D.DEPARTMENT_NAME;
    ```
    
- 6개월 내 거래 금액 확인
    
    ```sql
        SELECT A.ACCOUNT_ID 계좌ID, T.AMOUNT 거래금액, TO_CHAR(T.TRANSACTION_DATE,'YYYY-MM-DD HH24:MI:SS') 거래일, C.CUSTOMER_ID 고객ID, C.NAME 고객명 
        FROM ACCOUNTS A
        LEFT JOIN TRANSACTIONS T
        ON A.ACCOUNT_ID = T.ACCOUNT_ID
        LEFT JOIN CUSTOMERS C
        ON A.CUSTOMER_ID = C.CUSTOMER_ID
        WHERE MONTHS_BETWEEN(SYSDATE,T.TRANSACTION_DATE) <= 6;
    ```
    
- 특정 부서의 직무 별 직원 수
    
    ```sql
    SELECT COUNT(*)
    FROM EMPLOYEES E
    LEFT JOIN DEPARTMENTS D
    ON E.DEPARTMENT_ID = D.DEPARTMENT_ID
    WHERE D.DEPARTMENT_NAME IN ('Department 3', 'Department 4', 'Department 5', 'Department 6')
    GROUP BY E.JOB_ID;
    ```
    
- 계좌 유형 별 평균 잔액
    
    ```sql
    SELECT ACCOUNT_TYPE, TRUNC(AVG(BALANCE),2)
    FROM ACCOUNTS
    GROUP BY ACCOUNT_TYPE
    ORDER BY AVG(BALANCE) DESC;
    ```
    
- 각 계좌 별 거래 횟수
    
    ```sql
    SELECT A.ACCOUNT_ID, COUNT(*)
    FROM ACCOUNTS A
    LEFT JOIN TRANSACTIONS T
    ON A.ACCOUNT_ID = T.ACCOUNT_ID
    WHERE T.TRANSACTION_ID IS NOT NULL
    GROUP BY A.ACCOUNT_ID
    ORDER BY COUNT(*);
    ```
    
- 특정 기간의 고객 거래 내역
    
    ```sql
    SELECT RES.TOTAL
    FROM (
        SELECT ROW_NUMBER() OVER(ORDER BY SUM(T.AMOUNT) DESC) AS row_num, SUM(T.AMOUNT)TOTAL
        FROM TRANSACTIONS T
        LEFT JOIN ACCOUNTS A
        ON T.ACCOUNT_ID = A.ACCOUNT_ID
        WHERE TRANSACTION_DATE BETWEEN TO_DATE('2024-01-01','YYYY-MM-DD') AND TO_DATE('2025-12-31', 'YYYY-MM-DD')
        GROUP BY T.ACCOUNT_ID  
    ) RES
    WHERE row_num <= 10;
    ```
    
- 급여가 NULL인 직원
    
    ```sql
    SELECT E.NAME, D.DEPARTMENT_NAME
    FROM EMPLOYEES E
    LEFT JOIN DEPARTMENTS D
    ON E.DEPARTMENT_ID = D.DEPARTMENT_ID
    WHERE E.SALARY IS NULL
    ```
    
- 고객 별 가장 높은 대출 금액 조회
    
    ```sql
    SELECT 고객번호, 최대대출금액
    FROM (
        SELECT L.CUSTOMER_ID 고객번호,ROW_NUMBER() OVER(ORDER BY MAX(L.AMOUNT) DESC) row_num, MAX(L.AMOUNT) 최대대출금액
        FROM LOANS L
        LEFT JOIN CUSTOMERS C
        ON L.CUSTOMER_ID = C.CUSTOMER_ID
        GROUP BY L.CUSTOMER_ID
    )
    WHERE row_num <= 15;
    ```
    
- 특정 급여 구간과 부서 별 직원 분포
    
    ```sql
    
    SELECT D.DEPARTMENT_NAME, COUNT(*)
    FROM EMPLOYEES E
    LEFT JOIN DEPARTMENTS D
    ON D.DEPARTMENT_ID = E.DEPARTMENT_ID
    WHERE E.SALARY BETWEEN 7000 AND 15000
    GROUP BY D.DEPARTMENT_NAME
    HAVING COUNT(*) >= 5
    ORDER BY COUNT(*) DESC;
        
    ```
