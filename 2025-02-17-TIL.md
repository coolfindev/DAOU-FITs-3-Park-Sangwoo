### Servlet

- Java Program을 클라이언트가 호출, 브라우저에서 보려면 어떻게 해야 하는가
- interface Servlet을 이용
    - GenericeServlet - HttpServlet
    - HttpServlet 상속해서 구현
- 메소드
    - init() → 객체 생성 시 초기화 담당
    - service() → 클라이언트가 서블릿을 실행할 때 호출되는 메소드
        - 실제로 어떤 일을 하는가?
        - main은 아님!
        - 오버라이딩 하지 않음
    - doGet()/doPost() → GET/POST 방식으로 서버 프로그램 호출
    
    ```java
     @Override
        protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
            System.out.println("GET이 호출");
    
            //데이터 타입 먼저 지정
            resp.setContentType("text/html;charset=utf-8");
    
            //1. 결과를 돌려주기 위한 데이터 통로 열기
            PrintWriter out = resp.getWriter();
    
            //2. 통로를 이용해서 데이터를 전달
            out.println("<html>");
            out.println("<head>");
            out.println("<title>1차 결과</title>");
            out.println("</head>");
            out.println("<body>");
            out.println("안녕하세요!!");
            out.println("</body>");
            out.println("</html>");
    
            //3. 데이터 밀어내며 지우기
            out.flush();
            out.close();
        }
    ```
    
    - destroy() → servlet instance가 WAS에서 삭제될 때 수행되는 메소드
- annotation을 이용해서 이름을 설정할 수 있음
- 하나의 파일 내에서 이름 관리가 가능함

### 데이터 전달 방식

- GET
    - 쿼리스트링을 이용해서 데이터를 전달하는 방식 사용
    - 쿼리스트링은 특수한 형식을 가진 문자열
    - ?변수 = 값 & 변수 = 값 & 변수 = 값 ⇒ ?name = 홍길동 & age = 20 & address = 서울
    - [`http://localhost:8080/HelloServletProject/myServlet?name=홍길동&age=20`](http://localhost:8080/HelloServletProject/myServlet?name=%ED%99%8D%EA%B8%B8%EB%8F%99&age=20)
        - 보안성이 전혀 없음
        - 길이 제한이 있어서 길이가 긴 데이터 전달이 힘듦
- POST
    - 보안성이 약간 있음
        - url에 변수와 값에 대한 내용이 포함되지 않음
        - request header에 포함되어 데이터가 전달되기 때문에 길이 제한이 없음
        - HTML의 특수한 태그를 이용해서 서버쪽 프로그램(Servlet)을 호출하는 구조
    

### Servlet 실습

- 이전의 book 검색, mybatis로 연동

```java
package org.example.bookproject.controller;

import org.apache.ibatis.session.SqlSessionFactory;
import org.example.bookproject.dao.BookDAO;
import org.example.bookproject.mybatis.MyBatisSessionFactory;

import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.HashMap;
import java.util.List;

@WebServlet(value = "/book")
public class BookServlet extends HttpServlet {
    public BookServlet() {
        System.out.println("Book Servlet");
    }

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        req.setCharacterEncoding("utf-8");

        String radio = req.getParameter("radio_price");
        String keyword = req.getParameter("keyword");

        //-----------------mybatis ------------------
        SqlSessionFactory factory = MyBatisSessionFactory.getSqlSessionFactory();
        BookDAO bookDAO = new BookDAO(factory);

        List<HashMap<String,Object>> list =bookDAO.selectByTitleHashMap(keyword);

        resp.setContentType("text/html;charset=utf-8");
        System.out.println("--mybatis 연결 완료--");
        System.out.println(list);
        //데이터 타입 먼저 지정

        //1. 결과를 돌려주기 위한 데이터 통로 열기
        PrintWriter out = resp.getWriter();

        //2. 통로를 이용해서 데이터를 전달
        out.println("<html>");
        out.println("<head>");
        out.println("<title>검색 결과</title>");
        out.println("</head>");
        out.println("<body>");

        out.println("<h1>검색결과입니다.</h1>");
        out.println("<h3>검색키워드 : " + keyword + "</h3>");
        out.println("<h3>검색가격 : " + radio + "</h3>");

        out.println("<ul");
        for (HashMap<String,Object> map : list) {
            out.println("<li>" + map.get("BTITLE") + "," + map.get("BPRICE") + "</li>");
        }
        out.println("</ul>");

        out.println("</body>");
        out.println("</html>");

        //3. 데이터 밀어내며 지우기
        out.flush();
        out.close();

    }
}

```
