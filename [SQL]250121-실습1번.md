### 거래 테이블에서 계좌별 누적 거래 금액을 계산하시오.

```sql
select account_id, amount, sum(amount) over (partition by account_id order by transaction_date rows unbounded preceding) cum_sum
from transactions;
```

### 거래 테이블과 계좌별 최고 거래 금액을 출력하시오.

```sql
select account_id, amount, max(amount) over(partition by account_id) max_amount, round(amount/(max(amount) over(partition by account_id)),2) rate
from transactions;
```

### 대출 테이블에서 지점별 누적 대출 금액을 계산하시오.

```sql
select branch_id, amount, sum(amount) over(partition by branch_id order by loan_date rows unbounded preceding) cum_amount
from loans; 
```

### 계좌 테이블에서 고객별 평균 잔액을 계산하시오.(반올림하여 소수점 둘째 자리까지 출력)

```sql
select customer_id,account_id, balance, round(avg(balance) over (partition by customer_id),2) avg_balance
from accounts;
```
